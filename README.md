# HabitVisualizer
HabitVisualizer is a web app that tracks your daily habits and visualizes them

## Features

### 📝 Habit Input Section
- Add new habits with custom names
- Categorize habits (Health & Fitness, Productivity, Learning, Mindfulness, Social, Other)
- View and manage your current habits
- Toggle habit completion status
- Delete habits you no longer need

### 📊 Progress Charts
- Visual weekly overview of habit completion rates
- Interactive bar chart showing daily progress
- Color-coded legend for completed vs pending habits

### 🔥 Streak Counters
- Track your current streaks for each habit
- Visual progress bars showing streak milestones
- Motivational icons for different habit types

### 👥 Social Features
- View your social stats (Friends, Points, Rank)
- Leaderboard showing top friends this week
- Share your progress on social media
- Challenge friends to build better habits together

## How to Use

1. Open `index.html` in your web browser
2. Add a new habit using the "Add New Habit" form
3. Select a category for your habit
4. Click "Add Habit" to save it
5. Toggle habits as completed/incomplete using the circle button
6. View your progress in the charts and streak counters
7. Connect with friends using the social features panel

## Technical Details

- **Frontend**: Pure HTML5, CSS3, and JavaScript (ES6+)
- **Storage**: LocalStorage for persisting habit data
- **Design**: Modern, responsive layout with gradient backgrounds
- **No dependencies**: Works without any external libraries or frameworks
