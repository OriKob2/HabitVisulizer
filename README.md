# HabitVisualizer 🎯

A comprehensive web application that helps you track daily habits, visualize progress with engaging charts, maintain motivation through streak tracking, and celebrate milestones with achievements.

## Features

### 📊 Habit Tracking
- **Custom Habits**: Create personalized habits with categories and frequencies (daily/weekly)
- **Daily Progress**: Track daily completions with an intuitive interface
- **Habit Management**: Easy-to-use interface for adding, completing, and deleting habits

### 🔥 Streak Tracking
- **Current Streaks**: Real-time tracking of consecutive completion days
- **Longest Streaks**: Historical tracking of your best performance
- **Streak Badges**: Visual indicators showing your consistency

### 📈 Data Visualization
- **Progress Charts**: Interactive line charts showing daily completion trends
- **Category Distribution**: Doughnut charts displaying habit categories
- **Weekly Performance**: Bar charts with completion rate percentages
- **Dashboard Overview**: At-a-glance view of today's progress and active streaks

### 🏆 Achievement System
- **First Step**: Add your first habit 🌱
- **Week Warrior**: Maintain a 7-day streak 🔥
- **Monthly Master**: Maintain a 30-day streak ⭐
- **Habit Hero**: Track 10 different habits 🦸
- **Century Club**: Complete 100 habits 💯
- **Perfect Week**: Complete all habits for a week ✨
- **Social Butterfly**: Add your first friend 🤝
- **Goal Getter**: Complete your first goal 🎯

### 📅 Weekly Summaries
- **Progress Insights**: Detailed weekly completion statistics
- **Performance Metrics**: Total completions, daily averages, and best days
- **Trend Analysis**: Visual representation of weekly performance

### 👥 Social Features
- **Friend Connections**: Add friends for mutual accountability
- **Encouragement System**: Send motivational messages to friends
- **Encouragement Board**: View recent encouragements and stay motivated

### 🎯 Personalized Goals
- **Custom Goals**: Set specific targets for habit streaks
- **Progress Tracking**: Visual progress bars showing goal completion
- **Goal Achievements**: Celebrate when you reach your targets

### 📱 Additional Features
- **Local Storage**: All data persists in your browser
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Real-time Updates**: Instant feedback and statistics updates
- **Beautiful UI**: Modern gradient design with smooth animations

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No installation or server required!

### Running the App

1. Clone the repository:
```bash
git clone https://github.com/OriKob2/HabitVisulizer.git
cd HabitVisulizer
```

2. Open `index.html` in your web browser:
   - Double-click the file, or
   - Right-click and select "Open with" your browser, or
   - Use a local server:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Python 2
   python -m SimpleHTTPServer 8000
   
   # Node.js (if you have http-server installed)
   npx http-server
   ```

3. Visit `http://localhost:8000` in your browser

## How to Use

### Adding Your First Habit
1. Navigate to the "My Habits" tab
2. Fill in the habit form:
   - **Habit name**: What you want to track (e.g., "Read for 30 minutes")
   - **Category**: Type of habit (e.g., "Learning", "Health", "Productivity")
   - **Frequency**: Daily or Weekly
3. Click "Add Habit"

### Tracking Daily Progress
1. Go to "My Habits" tab
2. Click "Mark Done" next to any habit to complete it for today
3. Watch your streak grow! 🔥
4. Click again to undo if needed

### Viewing Statistics
1. Visit the "Dashboard" tab for today's overview
2. Check the "Statistics" tab for detailed analytics
3. View interactive charts showing your progress trends

### Unlocking Achievements
- Achievements unlock automatically as you reach milestones
- Check the "Achievements" tab to see all available achievements
- Unlocked achievements are highlighted in gold

### Setting Goals
1. Go to the "Goals" tab
2. Create a goal with a target number of days
3. Select which habit the goal applies to
4. Track your progress with visual progress bars

### Connecting with Friends
1. Navigate to the "Friends" tab
2. Add friends using their name and email
3. Send encouragement messages to stay accountable
4. View the encouragement board for motivation

## Technology Stack

- **HTML5**: Semantic structure
- **CSS3**: Modern styling with gradients and animations
- **JavaScript (ES6+)**: Application logic and data management
- **Chart.js**: Interactive data visualizations
- **LocalStorage API**: Client-side data persistence

## Data Privacy

All your data is stored locally in your browser using LocalStorage. No data is sent to any server. Your habits, achievements, and progress are completely private.
